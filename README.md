# Hi, I’m Darío 👋

Full stack developer with 10+ years of programming — first on my own projects, and since 2022 in product teams.

I work mainly with **React, TypeScript and Node**, plus **Capacitor** for mobile. I’ve built everything from CRMs and online stores to a CAD-style web editor, and lately I’ve been building **LLMs into products** (Anthropic API, Claude Code).

### Side projects

- **[oposita.io](https://oposita.io)**: study planner for people preparing Spanish public-sector exams, with real-time study rooms built on PixiJS.
- **[Solidity Workbench](https://github.com/daboy-dev/solidity-workbench)**: a VS Code extension that brings TypeScript-level tooling to Solidity and Foundry, from auto-imports and type-aware completion to project-wide renames checked by compiling.
- **[usage-line](https://github.com/daboy-dev/claude-code-usage-line)**: a Claude Code plugin that keeps your plan usage always on screen (the 5-hour session and the week, with time until each resets). One command to install, nothing to configure.
- **[Este Martes](https://estemartes.es)**: an automated pipeline that extracts what Spain’s Council of Ministers approves every Tuesday and shows the money behind it.
